Folder Description    
資料夾	中文名稱	存放內容	常見格式    
| 資料夾                | 中文名稱    | 建議存放內容                          | 常見格式                                |
| ------------------ | ------- | ------------------------------- | ----------------------------------- |
| `2. Slicing`       | 切層與掃描路徑 | 切層結果、每層輪廓、雷射掃描路徑、功率與速度設定        | `.cli`、`.slc`、`.csv`、`.gcode`       |

| `4. Coaxial_image` | 同軸影像    | 與雷射光路同方向拍攝的熔池、火花或製程影像           | `.png`、`.jpg`、`.tif`、`.avi`、`.mp4`  |
| `5. Global_image`  | 全域影像    | 從上方或側面拍攝整個粉床、加工區域或整個工件的影像       | `.png`、`.jpg`、`.tif`、`.avi`、`.mp4`  |
| `6. Measured_data` | 實際量測資料  | 感測器、相機、熔池監測、溫度、表面粗糙度、XCT及尺寸量測結果 | `.csv`、`.xlsx`、`.tdms`、`.h5`、`.dcm` |
